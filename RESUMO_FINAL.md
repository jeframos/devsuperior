# Inventário da documentação

A workspace reúne aplicações e exercícios de três cursos da DevSuperior. Este arquivo substitui o resumo anterior, que informava contagens e cobertura documental que já não correspondiam ao conteúdo do repositório.

## Cursos incluídos

### Java Spring Expert

- DSCatalog (backend)
- DSCommerce (módulo de testes com Rest Assured)
- DSMovie (JaCoCo e desafio Rest Assured, com projeto-base e módulo de prática)
- Movieflix (casos de uso)
- Desafio de validação e segurança
- Infraestrutura de apoio: PostgreSQL e pgAdmin com Docker Compose

### Java Spring Professional

- BDS Consultas, com seis desafios SQL: URI 2602, 2609, 2611, 2621, 2737 e 2990
- Desafio de componentes e injeção de dependência
- Desafio Consulta de Vendas (DSMeta)
- DSList (backend e materiais associados ao módulo CI/CD)
- DSCommerce, DSCrud e DSEvent
- Exemplos Spring Boot OAuth2/JWT, incluindo módulos independentes de authorization server e resource server

### Java Spring Reference

- DSLearn

## Como encontrar os detalhes

O [README da raiz](README.md) apresenta os cursos e os links dos projetos. O [índice](INDICE_READMES.md) lista a documentação de cada projeto, incluindo os seis exercícios SQL. Os requisitos, comandos de execução e particularidades devem ser consultados no README local e no `pom.xml` de cada módulo.

## Atualização

A lista acompanha a estrutura presente no repositório. Ao adicionar ou remover uma aplicação, atualize também o README da raiz e o [índice de READMEs](INDICE_READMES.md). Consulte [GUIA_MANUTENCAO.md](GUIA_MANUTENCAO.md) para o processo de manutenção.
