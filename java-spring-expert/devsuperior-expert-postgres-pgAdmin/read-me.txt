Comandos para consultar o Container:
  Para startar os containers
  - docker-compose up -d
  
  Consultar os containers em execução
  - docker ps [-a]
  
  Apagando containers
  - docker rm <Informe os 3 primeiros caracteres do 'CONTAINER ID'>
